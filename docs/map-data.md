# Map data (Phase 2, steps 7 and 8)

The monitor map draws country shapes and country-level markers from one committed file,
`crates/snitchwatch-kirigami/data/world-map.txt`. Nothing is fetched at build, test or run time;
the file is regenerated by hand at dev time only.

| Field | Value |
|---|---|
| Source | Natural Earth 1:110m admin-0 countries, GeoJSON |
| URL | https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_110m_admin_0_countries.geojson |
| Tag | v5.1.2 |
| sha256 of input | 6866c877d39cba9c357620878839b336d569f8c662d3cfab4cb1dbe2d39c977f |
| Licence | Public domain. Terms: https://www.naturalearthdata.com/about/terms-of-use/ (no attribution required; credit is courteous) |

The header of `world-map.txt` repeats the tag, hash and licence; a unit test fails if the hash here and
there drift apart.

## Regenerating

```
curl -fL -o ne_110m_admin_0_countries.geojson <URL above>   # into an empty scratch dir
sha256sum ne_110m_admin_0_countries.geojson                 # must match the table
python3 -I crates/snitchwatch-kirigami/scripts/gen_world_map.py ne_110m_admin_0_countries.geojson \
    > crates/snitchwatch-kirigami/data/world-map.txt
```

When bumping the tag, update `TAG`/`URL` in the script and the table above in the same change.

The header also records `degenerate_polygons`: polygons that collapse to under 3 grid points are dropped (the
round-trip test checks emitted + degenerate = source polygons).

## Format

`#` header lines, then one line per country: `CODE<TAB>NAME<TAB>CX,CY<TAB>PATH`. Coordinates are a
3600x1800 integer equirectangular grid (0.1 degree; `x = (lon+180)*10`, `y = (90-lat)*10`). `PATH` is an
absolute `M/L/Z` SVG path for `QtQuick.Shapes` (`PathSvg`), one subpath per polygon exterior ring (holes
are dropped). The centroid is the area-weighted centroid of the largest polygon, so FR lands in mainland
France. Loader: `src/geo/world_map.rs`.

## Code mapping

`ISO_A2_EH` is used, falling back to `ISO_A2`, which gives FR, NO and XK (Kosovo, user-assigned but emitted
by MaxMind) and TW. Two features with no code at all (N. Cyprus, Somaliland) are skipped.

## Countries with no shape at 110m

75 assigned codes have an empty path and only a marker. Their centroids are hand-entered approximate
geographic centres (within about a degree) from the CIA World Factbook geographic coordinates (public
domain), listed in `MANUAL` in the script: AD AG AI AS AW AX BB BH BL BM BQ BV CC CK CV CW CX DM FM FO GD GF
GG GI GP GS GU HK HM IM IO JE KI KM KN KY LC LI MC MF MH MO MP MQ MS MT MU MV NF NR NU PF PM PN PW RE SC SG SH
SJ SM ST SX TC TK TO TV UM VA VC VG VI WF WS YT. GF and SJ are folded into FR and NO in the source.

The resolver returns whatever ISO code the operator's `.mmdb` holds, so there is no code table in
`src/geo/`; the test checks all 249 assigned ISO 3166-1 alpha-2 codes plus XK. Pseudo-codes such as `AP`,
`EU` or `A1` have no marker.
