## Root cause of "ebpf does nothing today"
The repo config already requests `ebpf` (`packaging/system/opensnitchd-default-config.json:21`), but nothing
produces or installs `opensnitch.o`, `opensnitch-procs.o`, `opensnitch-dns.o`. The tower image builds the
daemon from Go source and installs no `.o` files. The only module-build recipe is prose (runbook 5a).
The modules are not CO-RE: they must be built against headers of the running kernel and paired with a daemon
from the same pin.
