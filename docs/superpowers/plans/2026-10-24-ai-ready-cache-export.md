# AI-ready Cache Summary Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a manually requested, redacted summary of the bridge's current connection cache, with an exact immutable preview and explicit private save.

**Architecture:** The bridge captures a bounded projection under its cache mutex, then filters, pseudonymizes and groups outside the mutex. A connection-owned export context routes bounded serialized replies privately; a session-aware Kirigami controller retains the returned UTF-8 artifact and delegates saving to a Qt-free filesystem helper. Protocol and filesystem foundations are independently testable before the final GUI integration.

**Tech Stack:** Rust 2021, Tokio, serde_json bounded writers, ring 0.17.14 HMAC-SHA256/SystemRandom, existing libc, cxx-qt 0.9.1, Qt6/Kirigami QML; MockOpensnitchd only.

**Spec:** [Owner-approved design](../specs/2026-10-24-ai-ready-cache-export-design.md), approved 2026-10-24; baseline `d543cfd5765ac62ef631d6542c4062db72e75053`, design commit `9c4ba1a88904dd4c743138e497cb2eacac17f085`.

## Global Constraints

- Owner approved implementation and TDD → PR → independent adversarial review/fix/re-review → exact-head green CI → merge. Approval persists; this plan adds no scope gate. Conditional security design review requires implementation evidence.
- Work only in `/tmp/snitchwatch-ai-export`, branch `feat/ai-ready-cache-export`; preserve primary `main`, unrelated `graft/`, and existing `dist/` artifacts. No host deployment, installation, live daemon, policy mutations or candidate-variable changes.
- SUMMARY ONLY: current bridge cache, no history/retention changes, raw rows, JSONL/CSV, readable destinations, configurable redaction, provider APIs/credentials/uploads, local runners, schedules, baselines or rule application.
- Authenticated socket/WS handshake remains the access boundary; no new UID isolation claim. Disclose shared-cache scope and possible identifying basenames/counts/times.
- IDs: 1–64 ASCII alphanumeric/hyphen; request ≤8 KiB UTF-8; selector ≤4 KiB; verdicts ≤5 unique enums; timestamps `0..=253402300799999`; window `[from, to)` with `from < to`; reject duplicate/unknown fields/options/filters. Refusals are static enums/text.
- Inspect newest 10,000 rows by insertion order; copy ≤8 MiB of required input strings; omit a row with any required field >4 KiB; emit ≤2,000 groups; artifact ≤1 MiB UTF-8 including envelope/prompt; full serialized WS reply ≤1 MiB +4 KiB **after escaping**. Reserve 14 bytes of that 1,052,672-byte budget for maximum WS frame header: actual JSON reply ≤1,052,658 bytes, sent as one outbound text frame; no additional transport-byte claims. Checked arithmetic; no scan beyond inspection bound.
- Snapshot under cache mutex; release before filtering/HMAC/grouping/serialization. Capture time/selection freeze once. New requests/cancellation/timeout/session changes drop GUI artifact; preview/save use identical returned UTF-8 bytes.
- At most two global workers, one active request per connection/session; immediate busy refusal, no waiting job queue. Deadline 10 seconds includes cache-lock wait; cooperative cancellation/disconnect; retain admission until actual worker exit. One pending artifact reply per session; discard unsent reply after five seconds, including socket-send wait.
- No `Replier` fallback to broadcast. Never broadcast artifact/refusal; reject these variants if accidentally received from broadcast. Bridge accepts no export paths.
- Random per-export HMAC key, app/destination domains, unambiguous encoding, 128-bit references; group by canonical identity/full 256-bit digest. On shortened-label collision regenerate key/export at most twice, then static refusal; never persist/export key. Fixed key/time/snapshot only in tests.
- Basenames only from validated `process_path`, never `process`; lexical validation plus `/usr/`, `/opt/`, `/app/`, `/bin/`, `/sbin/` allowlist; reject `..`, repeated separators and `(deleted)` suffix. Allowlisting proves neither ownership nor provenance.
- No raw row IDs, full paths, hostnames/IPs, rule names/text, args/env/UIDs/notices/diagnostic strings in DTO/preview/errors/logs. Filter controls may retain selectors; artifact/error/log must not. Basenames are untrusted plain text.
- Direction, durations and byte totals unavailable; source rows are observations, not measured network sessions. Evictions/restarts/upstream gaps/missed events unknown. Never imply absence of traffic, exact unexamined selection counts, throughput, repeat rate or baseline coverage.
- Save only after explicit action: generated non-overwriting `.json` in dedicated application-private exports directory (0700), file 0600; reject unsafe/symlinked directories, never chmod an arbitrary existing directory; exclusive no-follow temporary creation, atomic no-replace publication, cleanup on prepublication failure. Successful `renameat2` is the commit point: later directory-sync failure reports saved with unconfirmed durability, never failed/no file or retry.
- Logs/diagnostics/errors contain only static statuses and aggregate sizes, never request/filter/body/key/basename/destination/save path. Local success UI may show saved location. Cancellation before Save creates no file; after explicit Save starts, lock dismissal/filter mutation/new requests/cancel until outcome. Writer runs off Qt on frozen bytes. Exports remain until user removes them.

## Review Focus

1. Host-as-IP fallback, missing/empty paths and deceptive process labels must neither split equivalent IP destinations nor disclose false basenames — `destination_fallback_and_app_identity` (Task 2).
2. Large discarded fields, pending overflow and invalid timestamps must respect bounded inspection/copy while reporting only known coverage — `snapshot_ignores_unused_fields_and_reports_bounds` (Task 1).
3. Quotes, backslashes and control/Unicode text can fit the artifact yet overflow its nested WS string; fitting must remain bounded work — `escaped_reply_caps_drop_whole_groups`, `reply_serialization_probe_count_is_bounded` (Task 3).
4. Cancellation/reconnect while a blocking worker or socket send is stalled must not admit replacement workers, resurrect previews or retain expired replies — `cancel_timeout_holds_permits`, `expired_private_slot`, `stale_reply_cannot_restore_artifact` (Tasks 3, 4, 6).
5. Preexisting exports, symlink ancestors, directory swaps and postpublication sync failure must preserve files/permissions and distinguish committed saves from failed writes — `private_save_refuses_links_swaps_and_collisions`, `published_save_reports_unconfirmed_durability` (Task 5).
