## Conventions
- Integration-test binaries keep their names: `release_artifact` and
  `packaging_shape` become `tests/<name>/main.rs` (cargo autodiscovery);
  `bridge_protocol` keeps its `[[test]] path = "../bridge_protocol_test.rs"`
  root, so the file and every doc reference to it stay valid; children are
  `#[path]` modules.
- Shared helpers stay in the root module; children `use super::*;`, so no
  helper visibility changes were needed.

## Visibility edits (the only non-move changes)
- `mock_opensnitchd::rule_validation::validate_duration`: `pub(crate)`, as
  `loader.rs` reaches it through `crate::validate_duration` (re-imported
  privately in `lib.rs`). `validate_rule_shape` is re-exported (`pub use`).
- `bridge_runtime::link::LinkStatus::connecting`: `pub(super)`.
