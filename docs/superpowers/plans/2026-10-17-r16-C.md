# r16 group C: the remaining #115 test

## Item
A Unix HELLO that adopts nothing withdraws the rules list, and a leftover
delete then gets `NoDaemon`. Blocker: `RulesSync` read `Instant::now()`
directly, so a staged snapshot could not age past its 30 s TTL.

## Seam
`rules_sync.rs` has a private `now()`: `Instant::now()` in production
(identical code, inlined). Under `#[cfg(test)]` it adds a thread-local skew
that `advance_clock(by)` moves forward. Used by `stage_received`, `commit`
and `readopt`, the three staged-snapshot clock reads. Tests are
single-threaded per test, so the skew never leaks across tests. The inner
`PendingSnapshots` methods already take `now`, so they are untouched.

## Test
`blocklist_command::tests::a_hello_that_adopts_nothing_withdraws_the_list`:
stage, HELLO (adopts), advance 31 s, second stream's HELLO adopts nothing,
assert list withdrawn and `send_leftover_delete` is `NoDaemon`.
Mutants: TTL check never stale -> fails; `withdraw()` removed -> fails.
